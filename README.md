# 灰烬王冠 · Ashen Crown

一款以**中古战锤**为背景的中文文字跑团游戏。纯前端、零依赖、可离线双击游玩。

> 同人作品。背景设定借用 Warhammer Fantasy，全部文本与代码为原创。

## 快速开始

双击 **`灰烬王冠.html`**（或 `index.html`）即可在浏览器中游玩。

- 不需要安装、不需要联网、不需要服务器。
- 存档自动保存在浏览器的 localStorage 中；也可以在「系统」页导出 / 导入 JSON 存档。
- 推荐使用 Chrome / Edge / Firefox 的较新版本。

### 核心循环

1. 在灰港城中调查酒馆、神殿、码头与集市，收集线索。
2. 线索足够后深入墓园、下水道、档案室与市长宅邸。
3. 在旧礼拜堂面对灰烬祭司，决定王冠的命运——故事不会在这里结束。
4. 北上白蜡堡，与阿格尼丝、格罗姆、希尔达、埃德里克建立关系并招募同行者。
5. 守住白蜡堡，再杀上黑石隘口，在裂痕前做出最后的选择。

### 震旦开局：玉龙号

选择「震旦」不会进入通用的灰港序章，而是从停泊在港外的**玉龙号**开始，拥有一整段独立序章：

1. **甲板**：船长岑海确认星盘在船上失窃，锁没有被撬——叛徒就在船员里。鹤铳手**青蘅**作为临时援护加入。
2. **三条线索**（任选两条）：
   - 审问船员：揪出独眼骆，或在他的舱室里打一场。
   - 检查货舱：黑木箱、混沌符文、玉制指针。
   - 码头打听：盐仓七号、玉莲商馆的铜牌、市长的人。
3. **玉莲商馆**：主事沈夫人知道买家是谁。可以用使节身份、星盘残片或武力逼问。
4. **后巷伏击**：独眼骆带人堵住后巷，青蘅用鹤铳掩护。
5. **进城**：找回指针，它指向城北旧礼拜堂——无缝接回主线。

- 三个职业：
  - **玉勇**：玉鳞甲、长刀与盾，正面承伤。
  - **星象师**：星辰之矢、星辉护体，学识与魔法见长。
  - **鹤铳手**：鹤铳远程输出，装填后伤害很高。
- 序章新增线索：**星盘指针、独眼骆、玉莲商馆的买家**。
- **青蘅**：序章中作为临时援护，好感达到 40 可以在码头直接招募；第一章可以在「鹤铳的准星」个人任务里进一步提升好感与射击。
- **星盘完整度**：如果在货舱里先找到星盘，终章「以星盘校准裂痕」会削弱 Boss 12 点、治疗同伴 10 点、封印 +15；只找回残缺指针则分别降为 8 / 6 / +10。
- 后续专属内容：白蜡堡可以用使节身份请求协防（备战 +1、身份 +1）；黑石隘口可以用星盘校准裂痕（削弱 Boss、治疗同伴、提高封印成功率）。
- 所有结局都有震旦专属尾声。

### 同伴

| 同伴 | 定位 | 战斗方式 | 招募方式 |
| --- | --- | --- | --- |
| 阿格尼丝 | 医师 | 优先治疗最虚弱的队友 | 神殿线好感较高；交谈 / 赠礼 / 个人任务 |
| 格罗姆·铁牙 | 先锋 | 近战，替队伍分担攻击 | 酒馆线好感较高；帮他解决旧债 |
| 希尔达 | 斥候 | 每回合远程射击 | 第四章出城侦察时结识 |
| 埃德里克 | 盾卫 | 近战，年轻民兵 | 白蜡堡初始结识；训练与守夜 |
| 青蘅 | 鹤铳手 | 每回合远程射击 | 震旦序章结识；好感 40 可招募，个人任务在第一章 |

好感达到 40 可招募，最多 2 人同行；好感 30 解锁个人任务，70 以上解锁更好的后日谈。

### 规则速查

- 掷 `1d100`，小于等于目标值即成功；十位数差为 SL。
- 攻击与防守为对抗检定，命中后按倒序骰决定部位。
- 伤害 = 武器 + 力量加成 + SL 差 − 坚韧加成 − 护甲。
- 双数（11、22……）为暴击 / 大失败；100 必败。
- 伤口归零时消耗 1 点命运点保命；没有命运点则死亡。
- 剧情检定失败后，可花费 1 点命运点重掷。
- 混沌角色与部分选择会累积腐化，达到 3 / 6 / 9 时获得变异。

### 时间与生存

- 界面左侧显示「第 X 天 HH:00」与当前期限倒计时。
- 普通行动约 1 小时，检定约 2 小时，战斗约 2 小时，休息 8 小时；训练属性 4 小时、技能 3 小时、天赋 6 小时。
- **余烬仪式**：从第 1 天 08:00 起 72 小时。超时且还没进旧礼拜堂，会强制进入「迟到的黎明」——祭司已经完成仪式，Boss 额外 +10 伤口。
- **白蜡堡夜袭**：抵达白蜡堡后 48 小时。超时会直接进入「提前进攻」，准备不足，敌人更多。
- **裂痕扩张**：抵达黑石隘口后 24 小时。超时后 Boss +6 伤口，最终封印更难。
- 连续 24 小时不休息会疲劳（所有检定 -10），48 小时 -20；休息 8 小时可清除。疲劳会显示在左侧状态栏。
- 因此经验不能无限转化为战力：每次训练都要花时间，和调查、招募、休息争夺同一份期限。

### 选项提示

每个选项下方会显示：
- 可能用到的技能与难度；
- 预计耗时（⏳）；
- 选择后果（如「可能受伤」「备战 +1」「进入夜袭战」「戴上王冠 · 黑暗结局」）。

### 职业晋升与身份

每个职业有 4 个等级，头衔随职业变化，例如帝国士兵「新兵 → 老兵 → 军士 → 队长」、巴托尼亚骑士「侍从骑士 → 游侠骑士 → 圣杯骑士 → 骑士领主」。

- **功勋**：完成第一章 +1，守住白蜡堡 +1，击败灰烬领主 +1。
- **晋升条件**：Lv.2 需要 60 XP + 1 功勋；Lv.3 需要 150 XP + 2 功勋；Lv.4 需要 300 XP + 3 功勋。
- **晋升奖励**：伤口 +1、两项职业技能 +5；Lv.3 额外 +1 命运点；Lv.4 额外 +2 伤害、全护甲 +1。晋升仪式耗时 8 小时。
- **身份五档**：流民、平民、自由民、士绅、贵族。职业晋升会改变身份。
- **身份影响**：说服 / 威吓 / 魅惑 / 八卦检定获得 `(身份 - 2) × 5` 修正；商店价格随身份浮动（贵族约 85 折，流民约 105%）；部分选项只有士绅以上才能选（例如直接亮明身份进城、征召守军）。

## 文件结构

```
ashen-crown/
├─ 灰烬王冠.html        # 构建产物：单文件离线版（推荐分发）
├─ index.html           # 同上（便于本地打开）
├─ build.mjs            # 把 src 内联成单文件
├─ src/
│  ├─ data.js           # 种族、职业、技能、装备、法术、敌人
│  ├─ rules.js          # 检定、战斗、伤害、成长、腐化
│  ├─ content.js        # 场景、选项、随机遭遇、结局
│  ├─ ui.js             # 渲染与交互
│  ├─ main.js           # 启动与存档
│  ├─ style.css         # 样式
│  └─ shell.html        # HTML 模板
└─ tests/
   ├─ sim.mjs           # 规则 + 剧情自动对局测试
   └─ ui-smoke.mjs      # 最小 DOM 桩渲染测试
```

## 开发

```bash
node build.mjs          # 重新生成 index.html 与 灰烬王冠.html
node tests/sim.mjs      # 规则、战斗、自动通关、存档往返
node tests/ui-smoke.mjs # 各界面渲染冒烟测试
```

修改内容时：

- 加种族 / 职业 / 敌人 / 武器：改 `src/data.js`。
- 加剧情：在 `src/content.js` 的 `scenes` 里加场景，选项支持
  `goto`、`check`（成功 / 失败分支）、`combat`、`effects`、`stay`、`show`、`disabled`。
- 改数值：`src/rules.js` 顶部的伤害与伤口公式、`data.js` 的敌人属性。
- 构建后两个 HTML 会同步更新。

## 已知限制 / 可以继续加的东西

- 五章通关约 40–70 分钟；可以继续写第六章（例如追击逃入荒原的余烬残部）。
- 同伴没有独立好感剧情线，个人任务各只有一幕；可以继续扩写。
- 没有商店出售、装备切换 UI（自动选用伤害最高的近战 / 远程武器）。
- 没有难度选项；想要更硬核可以调低玩家命中加成或提高敌人伤口。
- 种族专属内容集中在开场、第四章进城方式与第五章仪式选项，还可以继续增加。
- 战斗存档会暂停自动保存，避免中途状态不完整。
